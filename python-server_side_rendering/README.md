# Python - Server-Side Rendering

## Description
Ce projet explore le rendu côté serveur (SSR) en Python. Il couvre la génération de contenu dynamique via templating, la lecture de données depuis différentes sources (JSON, CSV, SQLite), et l'utilisation de Flask avec le moteur de templates Jinja2.

## Tâches

| Tâche | Fichier | Description |
|-------|---------|-------------|
| 0 | `task_00_intro.py` | Génère des fichiers d'invitation personnalisés à partir d'un template |
