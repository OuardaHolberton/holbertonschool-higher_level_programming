## 🗄️ Python Object Relational Mapping

Connexion à MySQL via MySQLdb puis abstraction avec SQLAlchemy.

| Tâche | Description |
|-------|-------------|
| MySQLdb | Requêtes SQL directes depuis Python |
| SQLAlchemy | Mapping objet-relationnel |
| CRUD complet | Create, Read, Update, Delete |

## 📦 Python Serialization

## 🌐 RESTful API

API complète avec Flask, sécurisée par JWT et Basic Auth.

| Route | Description |
|-------|-------------|
| POST /add_user | Créer un utilisateur |
| GET /users/name | Récupérer un utilisateur |
| POST /login | Obtenir un token JWT |
| GET /protected | Route protégée token requis |
