# JavaScript - DOM Manipulation

## Description
Ce projet couvre la manipulation du DOM en JavaScript : sélection d'éléments HTML, modification de styles et de contenu, gestion d'événements, et requêtes réseau (XmlHTTPRequest / Fetch API).

## Requirements
- Testé sur Chrome (version 57.0+)
- Code compatible `semistandard`
- Pas d'utilisation de `var`
- Pas de rechargement de page pour les actions DOM
