# JavaScript - Warm up

## Description
Ce projet est une introduction aux bases de JavaScript : variables (`let`, `const`), types de données, structures conditionnelles, boucles, fonctions et manipulation d'objets/tableaux.

## Résumé des tâches

| Tâche | Fichier | Description |
|-------|---------|-------------|
| 0 | `0-javascript_is_amazing.js` | Affiche "JavaScript is amazing" via une constante |

## Requirements
- Node.js 14.x
- Code compatible `semistandard`
- Chaque fichier commence par `#!/usr/bin/node`
- Chaque fichier doit être exécutable
